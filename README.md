# Bank-data-analytics
Bank Loan Analysis Dashboard using Power BI, SQL and Excel

An end-to-end banking loan analysis using **SQL, Power BI, Tableau and Excel**. It tracks loan, collection, interest and default KPIs across branches, states, products and time.

![Tableau Dashboard](Bank%20Analytics%20Tableau%20Dashboard.png)

## Objective
Analyse banking customer and loan data to track key performance indicators (KPIs) and understand loan performance by branch, state, product, religion, grade and loan status.

## Tools Used
| Tool | Purpose |
|---|---|
| SQL (MySQL) | Data extraction, aggregation and analysis |
| Excel | Data cleaning, pivot tables and KPI dashboard |
| Power BI | Interactive dashboard with slicers and filters |
| Tableau | Interactive dashboard with filters |

## What I Did
- Cleaned and prepared the banking data (missing values, duplicates, data types)
- Wrote SQL queries to extract, aggregate and analyse the data
- Built KPI dashboards in Excel, Power BI and Tableau
- Added slicers and filters for state, region and year

## KPIs Tracked
- Total Loan Amount Funded
- Total Collection and Total Interest
- Verified vs Non-Verified Loans
- Default Loan Count and Delinquent Loan Rate
- Branch-wise, State-wise, Product-wise, Religion-wise and Age Group-wise Loan

## Key Insights
> Check each number against your dashboard before publishing.
- Total loan amount funded is about **$732.7M**, and total collection is about **$814.9M**, with **$155.3M** earned as interest.
- **Punjab** has the highest state-wise loan amount, followed by Haryana.
- **Product group XLG** accounts for the largest share of loans, far ahead of the other product groups.
- There are about **1,020 default loans** across the portfolio.
